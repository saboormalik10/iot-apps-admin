Observator Weather Station - Windows release
============================================

There are two ways to install; they do the same thing:
  * observator-weather-<version>-setup.exe - a setup program (simplest), or
  * this zip.

To INSTALL from this zip:
  1. Unpack it anywhere (for example the Desktop).
  2. Double-click install.cmd and allow administrator rights.
  3. Enter the first administrator's email and password.
  It prints the address to open in a browser, e.g. http://station-pc:3201

To UPGRADE an existing install:
  Unpack the new release anywhere EXCEPT C:\Observator, then double-click
  its upgrade.cmd. Everything is backed up first; all data is kept.

Guides (open in any text editor or browser):
  docs\INSTALL.md          installing, and pointing the sensor at the PC
  docs\OPERATIONS.md       status, backups, restore, upgrade, passwords, clock
  docs\TROUBLESHOOTING.md  when something is not working
  docs\USER-GUIDE.md       for people using the portal

After installing, the tools are in C:\Observator:
  status.cmd  backup-now.cmd  restore.cmd  reset-password.cmd  uninstall.cmd

Versions of the bundled programs: versions.txt
