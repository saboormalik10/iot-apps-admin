# Porting log — cloud fixes to carry across

This project began as a copy of the cloud portal and does not share code with it. A fix
made in the cloud portal does **not** reach this project on its own.

Record here anything from the cloud project that should be carried across, and tick it
off when it has been.

**What belongs here:** calculation fixes, QC rules, security fixes, data-integrity fixes.
**What doesn't:** anything about SFTP, customers, the super admin, provisioning, or cloud
hosting — those parts were removed from this project.

## Baseline

Copied from the cloud project at commit **`e39dd7f`** on 22 September 2026

Not copied: `node_modules`, build output, every `.env` file, and `backend/backups/` —
